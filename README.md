# Sharks Need Us

Shark awareness website by Harriet Jackson. Live at https://sharksneedus.com

- `index.html` – the main site
- `steve.html` – the Steve Backshall page
- `img/` – photos, illustrations and the logo
- `_redirects` – Netlify redirect rules

Hosted on Netlify. Every push to `main` redeploys the site automatically.
